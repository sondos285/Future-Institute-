 اسم المشروع: موقع معهد المستقبل للتدريب والتطوير (Future Institute)

 فكرة المشروع:
موقع ويب تعريفي وتفاعلي حديث لـ "معهد المستقبل (Future)"، وهو معهد تعليمي رائد يهدف إلى تمكين الشباب وتطوير مهاراتهم لمواكبة سوق العمل. يتيح الموقع للزوار استكشاف البرامج التدريبية المتاحة، ومعرفة تفاصيل الدورات، والتسجيل فيها إلكترونياً وبشكل سلس.

 أقسام الموقع الأساسية (HTML Structure):
 (Header): يحتوي على شعار المعهد (Future) وقائمة التنقل بين أقسام الموقع (الرئيسية، الدورات، عن المعهد، اتصل بنا).
الواجهة الترحيبية (Hero Section): مساحة بصرية جذابة تحتوي على عنوان تحفيزي (صنّع مستقبلك مع Future) مع زر تفاعلي للانتقال الفوري لطلب التسجيل.
مسارات التدريب والدورات (Courses Section): بطاقات (Cards) منسقة بشكل احترافي تعرض التخصصات المتاحة في المعهد وهي:
  1. 💻 تطوير البرمجيات وتكنولوجيا المعلومات (Programming)
  2. 🎨 التصميم والجرافيكس (Graphics Design)
  3. 📸 التصوير الرقمي وإنتاج الفيديو (Photography)
  4. 🇬🇧 اللغة الإنجليزية (English Language)
  5. 📱 صيانة وبرمجة الهواتف (Mobile Learning)
  6. 🖥️ أساسيات الحاسوب ورخصة القيادة الدولية (Computer Skills)

 الأدوات المستخدمة:
HTML5: لبناء هيكل الموقع المطور والمنظم.
CSS3: لتنسيق الألوان المستوحاة من الهوية البصرية للمستقبل، وضبط المسافات، وجعل التصميم متوافقاً مع كل الشاشات.
JavaScript: لإضافة الحيوية والتحقق من التفاعلات مع المستخدم.
